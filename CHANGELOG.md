# Changelog

## [0.1.0.0] - 2026-08-07

### Added

- Added the Electron review workspace with project and session navigation, transcript import, analysis controls, evidence inspection, requirements, assumptions, open questions, recommendations, and export actions.
- Added a bundled Northstar Returns Portal demo project and session for product demonstrations.
- Added versioned transcript amendments with stale-analysis invalidation and a re-analysis workflow.
- Added project, session, and transcript deletion flows with confirmation dialogs.

### Changed

- Added a direct home affordance through the Story Agent brand and renamed file loading to Import file.
- Standardized review cards, action labels, icons, focus states, contrast, responsive behavior, and light/dark theme surfaces across all tabs.
- Made evidence access explicit with View evidence actions and high-contrast transcript context highlighting.

### Fixed

- Removed ambiguous requirement details and claim-ID dropdown controls.
- Replaced unlabeled decline controls with explicit Decline actions.
- Fixed low-contrast gray review content and transcript context styling.
